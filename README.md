# Intelligent Traffic Management System

**100% Software-Based IoT Simulation & Adaptive Traffic Signal Optimization**

A high-reliability, modular traffic management system designed for external practical examinations, academic presentations, and smart city traffic research.

> **Academic & Examination Notice**:
> This system is **100% software-based**. It requires **no physical hardware**, microcontrollers, physical sensors, cameras, relays, or IoT cloud brokers. All vehicle arrivals, queue estimates, and sensor readings are generated by an autonomous, software-based stochastic simulation engine and are explicitly marked as **SIMULATED**.

## How to Run on Windows / VS Code

### Option 1: Using the Launcher Scripts
- Double-click `run.bat` or run in terminal:
  ```powershell
  .\run.bat
  ```
  or via PowerShell:
  ```powershell
  .\run.ps1
  ```

### Option 2: Using Python Directly
1. Open the project folder in VS Code.
2. Open a terminal (**Terminal → New Terminal**).
3. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
   *(If `python` is not in your system PATH, use `py -m pip install -r requirements.txt` or your local Python path)*
4. Start the server:
   ```powershell
   python app.py
   ```
5. Open your web browser at:
   **http://127.0.0.1:5000**
6. Keep the terminal window open while interacting with the dashboard. Press `Ctrl + C` in the terminal to stop the server.

## REST API Specification

| Endpoint | Method | Payload Example | Description |
| :--- | :---: | :--- | :--- |
| `GET /` | `GET` | *None* | Serves the web dashboard. |
| `GET /api/health` | `GET` | *None* | Operational health check endpoint. |
| `GET /api/state` | `GET` | *None* | Full network state snapshot and metrics. |
| `POST /api/tick` | `POST` | `{}` | Advances simulation by one step (manual stepping). |
| `POST /api/control` | `POST` | `{"action": "pause"}` | Pause simulation. |
| `POST /api/control` | `POST` | `{"action": "resume"}` | Resume simulation. |
| `POST /api/control` | `POST` | `{"action": "auto"}` | Enable dynamic adaptive signal control. |
| `POST /api/control` | `POST` | `{"action": "manual"}` | Enable operator manual signal override. |
| `POST /api/control` | `POST` | `{"action": "speed", "speed": 2.0}` | Set simulation speed multiplier (0.5x, 1.0x, 2.0x, 4.0x). |
| `POST /api/control` | `POST` | `{"action": "reset", "seed": 42}` | Reset simulation to initial state with optional seed. |
| `POST /api/signal` | `POST` | `{"junction": "J1", "direction": "North"}` | Manually force green signal (Manual mode only). |
| `POST /api/traffic` | `POST` | `{"junction": "J1", "direction": "North", "amount": 5}` | Inject a burst of simulated vehicles into a lane approach (1–25). |
| `POST /api/settings` | `POST` | `{"min_green": 8, "max_green": 35}` | Configure adaptive timing rules (min: 3–20s, max: 8–60s). |

## Key Examination Demonstration Features

1. **Deterministic Demonstration (Repeatable Exam Runs)**:
   - Click **Reset** on the dashboard.
   - Enter an integer seed (e.g. `42`).
   - The simulation will generate the exact same vehicle arrival sequence and signal transitions every time, allowing repeatable examination demonstrations.
2. **Autonomous Background Worker**:
   - The simulation runs on a dedicated server-side daemon thread. Opening multiple browser tabs or closing the dashboard does not distort the simulation clock.
3. **Simulation Speed Control**:
   - Easily speed up (2.0x, 4.0x) or slow down (0.5x) the simulation using the toolbar buttons to showcase long-term queue evolution.
4. **Traffic Injection Demonstration**:
   - Click the **+5 Cars** button on any lane approach to simulate a sudden surge of traffic.
   - Observe the adaptive algorithm detect the increased queue pressure and prioritize that approach with an extended green phase.
5. **Anti-Starvation Guarantees**:
   - Low-volume approaches track `cycles_without_green`. If cross-traffic holds green repeatedly, waiting lanes receive priority boost to prevent starvation.
6. **Operator Manual Override**:
   - Switch to **Manual** mode and click any `Direction → Green` button to demonstrate emergency or operator override capabilities.
